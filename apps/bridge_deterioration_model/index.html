One HyperNetwork, one forecast per bridge.

Every bridge gets its own deterioration forecast. A shared HyperNetwork learns the relationship between structural attributes, local climate, and condition trajectory, then generates a custom Long-Short-Term-Memory network per structure. The primary focus is PacTrans Region 10 (Washington, Oregon, Idaho, Alaska); the nationwide view loads automatically when the full-US dataset is available.

Pick your state at State comparison, or select a bridge directly.

Bridge HyperNetwork - PacTrans Small Project, Washington State University. Data sources: FHWA NBI, State DOTs, NOAA, USGS.
